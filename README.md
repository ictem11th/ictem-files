# سامانه فایل‌های کنفرانس ICTEM

یک سایت کاملاً استاتیک (بدون سرور و دیتابیس) برای انتشار PDF و تصویر با **لینک ثابت**.

- لینک هر فایل: `https://USERNAME.github.io/REPO/?id=SLUG`
- با جایگزین کردن فایل از پنل، `SLUG` و لینک عوض نمی‌شود؛ فقط محتوا تازه می‌شود.
- پنل نویسنده: `https://USERNAME.github.io/REPO/admin/`

## راه‌اندازی (یک بار، حدود ۱۰ دقیقه)

1. در GitHub یک ریپوی **Public** بسازید (مثلاً `ictem-files`) و تمام محتوای این پوشه را در آن آپلود کنید
   (`.nojekyll` و پوشه‌های `files` و `assets` هم باید باشند).
2. `Settings → Pages` → Source را روی **GitHub Actions** بگذارید (فایل `.github/workflows/pages.yml` کار انتشار را انجام می‌دهد؛ با هر تغییر روی شاخه `main` خودکار اجرا می‌شود).
3. در تب `Actions` صبر کنید اجرا سبز شود؛ بعد سایت روی `https://USERNAME.github.io/REPO/` بالا می‌آید.
4. ساخت توکن برای پنل:
   `GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate`
   - Repository access: **Only select repositories** ← فقط همین ریپو
   - Permissions → Repository permissions → **Contents: Read and write**
   - تاریخ انقضا را کوتاه بگذارید (مثلاً ۳۰ تا ۹۰ روز)
5. وارد `/admin/` شوید، نام کاربری، نام ریپو و توکن را بدهید و «ورود» بزنید.

## استفاده روزمره

- **فایل جدید:** شناسه (مثلاً `program-day1`)، عنوان و فایل را بدهید ← «انتشار».
- **تغییر محتوا با لینک ثابت:** کنار فایل «ویرایش / جایگزینی» ← فایل جدید را انتخاب کنید ← ذخیره.
  (می‌توانید PDF را با تصویر هم عوض کنید؛ لینک همان می‌ماند.)
- **حذف:** لینک از کار می‌افتد.
- بعد از هر تغییر، GitHub Pages معمولاً ۱ تا ۲ دقیقه برای به‌روزرسانی نیاز دارد.
- بدون پنل هم می‌شود: فایل را در `files/` بگذارید و یک مورد به `files.json` اضافه کنید.

## نکات مهم

- ریپو Public است، پس **هر فایلی که آپلود می‌کنید برای همه قابل دسترس است**؛ چیز محرمانه نگذارید.
- توکن فقط داخل localStorage مرورگر خودتان می‌ماند. روی کامپیوتر عمومی از «خروج» استفاده کنید.
- سقف هر فایل در پنل ۲۰ مگابایت است (محدودیت عملی API گیت‌هاب).
- شناسه (`SLUG`) بعد از ساخت قابل تغییر نیست تا لینک‌ها نشکنند.
- پنل برای کار با `api.github.com` به اینترنت نیاز دارد. اگر از ایران باز نشد، یک بار با اتصال دیگری/VPN فایل را آپلود کنید؛ بازدیدکنندگان فقط به `github.io` نیاز دارند.

## اجرای محلی برای تست

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## انتقال به هاست دیگر

چون همه چیز استاتیک است، همین پوشه را بدون تغییر می‌شود روی Cloudflare Pages، Netlify، ArvanCloud و … هم گذاشت.
فقط آپلود از پنل به GitHub وابسته است؛ در هاست دیگر فایل‌ها را دستی در `files/` و `files.json` بگذارید.

## ساختار

```
index.html          صفحه عمومی (فهرست یا نمایش فایل با ?id=)
admin/index.html    پنل نویسنده
files.json          فهرست فایل‌ها (id, title, file, type, updated)
files/              خود فایل‌ها
assets/             استایل، اسکریپت، pdf.js و فونت وزیرمتن (همه محلی، بدون CDN)
```
